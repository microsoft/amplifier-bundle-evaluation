# Evaluation

You have access to the `amplifier-bundle-evaluation` bundle for evaluation needs in the Amplifier ecosystem. Currently the way to interact with this bundle is to use the `evaluation` mode.

## When to Use

- When the user wants to test the quality of their changes
- When the user wants to compute metrics related to what they are building

## How to Use

The only way to use this is for the user to type `/mode evaluation "<their ask>"`
